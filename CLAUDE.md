task: create a mobile-first mini note taking crm app for MOBILATOR - a manufactuing woodworks brand
ui language - romanian
goal of the app is for the management of mobilator to go to different furniture manufacturers meet ups and network new connections and collaborators, this app should serve that purpose, so instead of writing down new companies down on paper, you can write them down here as new connections.

features
tight openai integration - using openai API the app is deeply ai-first, you can dictate new stuff, ask questions, ask ai to do more research, add new contacts and more; ai will organize everything to be as clean and intuitive as possible - brand logo, brand name, management, phone number, notes, checklists, shortcuts etc.

follows mobilator design language from assets\ui references folder, is mobile first

uses supabase + Edge Function, stores data with authentication, supports json exports of contacts

supports creating calendar events from the app and other system shortcuts like contacts, mail, etc.
